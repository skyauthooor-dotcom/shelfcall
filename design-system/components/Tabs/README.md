# Tabs

Filters over one list. The bookseller's request feed uses it — *All*, *Not answered by you*, *Open-ended* — and so does the reader's theme setting.

Tabs switch what is shown, never where you are. Navigation between screens is the top bar, not tabs. If picking one would change the URL to a different page, it is not a tab.

Keep the set to two to four, label them with the thing being shown, and make the first one the unfiltered view. A count belongs in the tab only when it is the reason to press it.

## What the consumer provides

The triggers with `data-state` on the active one, and the content. The list scrolls horizontally on a narrow screen rather than wrapping, so a tab is never half visible.
