# Empty

What a list says when it has nothing in it. Shelfcall has a lot of these, because a marketplace starts empty on every side.

Three parts, and all three are required: what is not here, **why**, and what to do next. *No deliveries right now. A job appears when a shop marks an order ready for the courier.* The middle part is the one people skip and the one that does the work — an empty state that only says `No results` teaches nobody anything.

Where there is a sensible action, put one button in `EmptyContent`. Where there genuinely is nothing to do but wait, say that instead of inventing a button.

## What the consumer provides

The title, the description explaining why, and an optional action. Never an illustration and never an emoji.
